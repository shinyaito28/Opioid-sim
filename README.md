# Anesthesia PK/PD Simulator

React / Vite の投与スケジュール・濃度推移シミュレーターです。患者属性、ボーラス、持続投与からモデルのCp・Ceを計算します。計算結果と臨床的妥当性は別です。実測BISや患者個別の呼吸抑制、覚醒を検証するアプリではありません。

既存の依存がある環境での実行手順:

```sh
npm run dev
npm test
npm run build
npm run preview
```

`npm test`はNodeの標準テストランナーを使用し、ネットワークや実患者データを必要としません。主要4薬剤の独立した数値解との比較、単位、保存、時刻、入力、持続投与の回帰を確認します。

保存先はブラウザのlocalStorageです。読み込めない保存内容は上書きせず保持します。計算版が異なる保存済み比較線は保持したまま非表示にします。

[2026-10-04の修正と検証範囲](docs/bugfixes_2026-10-04.md)を参照してください。ビルド、Gitへのcommit/push、Vercelへの公開は別の操作です。

[ローカルUI試作の操作と保存互換性](docs/ui_prototype_2026-10-04.md)：頻用5薬剤の入力、ポンプ別の速度変更・停止・並行追加、実施済み／予定の区分をまとめています。予定を除く計算では、前の投与区間も元の入力条件から再計算します。

表示言語は英語が初期設定です。EN／JPで日本語も選べ、保存した選択を維持します。頻用ショートカットにはレミマゾラムを含みます。
