# iPhone PWAのタイトルの曇りへの対策案

本番 b8816f53a17b81bd1b5253e43d6681be68f35f88 を基点とするローカル修正です。push・デプロイは行っていません。

## 確認した現象と原因候補

ユーザー提供の IMG_8561.png（Library: libfile_09297dda24c48191b1eff0261d6472d8）を取得して確認しました。アプリのタイトルと波形アイコンだけにぼかしが見え、時刻、患者情報、Saved Cases、言語ボタンは鮮明です。下端には濃紺の帯があります。

アプリのヘッダーは不透明で、filter・backdrop-filter は none です。glass クラスは付いておらず、タイトルに重なるマスクや疑似要素もありません。従来の白帯対策では、文書全体のスクロールを止め、safe-area より下の .simple-app に内部スクロールを設けていました。ただし、タイトルもそのスクロール領域の中に残っていました。

今回の原因候補は、iOS側のスクロール端効果とタイトルの重なりです。[WebKitのiOS側実装](https://raw.githubusercontent.com/WebKit/WebKit/main/Source/WebKit/UIProcess/API/ios/WKWebViewIOS.mm)には、上端の色延長領域や可視インセットを条件にシステム側の端効果を切り替える処理があります。[固定要素の色延長と端効果の処理](https://raw.githubusercontent.com/WebKit/WebKit/main/Source/WebKit/UIProcess/API/Cocoa/WKWebView.mm)も別に存在します。この効果は、アプリのCSSで指定するぼかしとは別の処理です。

ただし、これは画像とコードからの仮説です。使用中のiOSバージョンは不明で、該当端末のWeb Inspectorや実機再現による原因確定はできていません。下端の帯についても、システム領域かアプリの背景かを画像だけで断定していません。

## 変更内容

- ヘッダーを本文の内部スクロールから分離しました。インストール版PWAだけでヘッダーを不透明な固定領域にし、タイトルがスクロール内容として上端へ流れ込まない構造にしています。
- ヘッダーの実際の高さをResizeObserverで測り、本文をその下に配置します。言語切り替え、文字の折り返し、safe-areaの変化、回転に追従します。ノッチやタイトルの高さを固定値で推測しません。
- safe-areaの上余白はヘッダーに一度だけ加えます。VisualViewportへの追従、本文入力の表示位置調整、ダイアログの独立配置は維持しています。
- PWAではヘッダーと操作ボタンが上部に残り、本文だけがスクロールする挙動に変わります。通常のブラウザでは従来どおり、PCはsticky、狭い画面はページと一緒にヘッダーがスクロールします。
- PWAのHTML識別URLを ios-fixed-header-v4 に更新しました。ステータスバー指定black、濃紺の初期背景、manifestのstart_urlとscopeは維持しています。

PK/PD計算、薬剤・モデル、投与入力、保存スキーマ、保存キー、Fitと軸操作は変更していません。既存データの削除、キャッシュ一括削除、SW登録解除、PWAの再インストールも行っていません。
