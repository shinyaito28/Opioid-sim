# グラフを中心にした入力・編集の試作

基点は本番コミット11f125f、試作ブランチはui-workbench-prototypeです。本番やGitHubには反映していません。

## 配置

New caseを最初の薬剤入力の上に配置しました。現在の症例は別名で保存済み症例へ退避し、既存の名前付き症例を上書きしません。同じ内容が既に保存されていれば重複を作りません。退避先を含む状態の保存が成功してから画面を切り替えます。Undo/Redoでも元の作業状態に戻せます。元データのバックアップキーと保存形式は変更していません。

英語表示の日本語ボタンはJPと表示します。スクリーンリーダー用の名前は日本語 / Japaneseです。

PCでは薬剤・時計・投与量を横長のパネルにまとめました。1280px幅の独立したEdgeで、入力パネルは442pxから197pxへ縮小しています。グラフの横にパネルは置きません。グラフは全幅を使い、描画幅は902pxから1142pxに広がりました。スマホの入力欄、時計ボタン、安全領域とPWAの内部スクロール処理は維持しています。

履歴はグラフのすぐ下で直近4件を表示し、全件へ切り替えられます。選んだ投与の時刻・量・速度・単位は同じ場所で編集し、有効な値を220ms後またはフォーカスを外した時に反映します。上の入力欄へスクロールしません。空欄や入力途中の値は反映せず、持続投与の時刻衝突も既存の検証で拒否します。新しい投与の時計と、履歴編集の時計は分離しています。

## 投与の目印

マーカーは曲線上へ重ねず、X軸の下の専用レーンに配置しました。各投与の細い目盛りは正確な時刻を保ち、近接・同時刻の投与は件数付きの矢印にまとめます。選ぶと時刻・薬剤名・単回量または持続速度と単位を表示します。持続の開始、速度変更、停止、インポートされた有限持続の終了を区別します。有限持続の終了は表示用の目印だけで、保存イベントを追加しません。

白抜きの矢印は現在時刻より後の条件です。投与済みかどうかの医学的な判定を意味しません。従来のX/Y軸バー、正確な範囲指定、自動Y上限、モデル選択は引き続き使えます。

## 追加：専用バー付近の数値表示

グラフ本体はそのままに、下側の投与マーカー専用バーへ番号を付け、その直下に小さな数値と単位を常時表示しました。薬剤名と薬剤色、時刻、単回投与・持続開始・速度変更・停止・終了の区別を表示します。単回投与は投与量、持続投与は入力単位での速度であり、累積量は表示していません。停止・終了も0と速度単位を表示します。

数値はホバーや選択なしで読めます。近接投与は従来どおり同じ矢印にまとめますが、数値欄では各イベントの時刻と値を個別に残します。表示欄は通常の文書フローで折り返し、濃度曲線へ重ねたり、グラフ幅を削ったりしません。大量の投与条件では数値欄の縦幅が増えます。

追加後は全123テストが成功しました。全薬剤の対応速度単位、単回量と速度の区別、停止0、英日両方の未選択時の数値出力、100件の同時刻投与を省略しないことを確認しています。グラフ本体の描画部分、X/Y軸コントロール、マーカーのグループ化と座標のコードは追加前と同一です。クリーンなPWAビルドも成功しました。

この追加ではブラウザ操作テストを実行していません。実際の画面幅での折り返し、視認性、新しい画像、iPhone実機の表示は未確認です。先に共有した3枚のスクリーンショットは、この数値追加より前の試作です。
