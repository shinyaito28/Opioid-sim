# Anesthesia PK/PD Simulator — 直近の機能追加サマリー (2026-05-03)

これは Phase 5-H-2 から 5-H-5 までの追加分を、コードを見ない人向けにまとめたメモです。
前回のサマリー (`feature_summary_2026-04-29.md`) は Phase 5-H-1 までをカバーしていて、その時点では「**iPhone/iPad ではチャートクリックが効かない**」という制約がありました。これがどう解消されたか、そこから何が広がったかを書きます。

---

## 1. iPhone/iPad でもチャートをタップできる (5-H-2)

**前:** PC のマウスクリックではチャート上のフローティング popover (Phase 5-H-1) が出るが、iPhone/iPad の指タッチでは反応しなかった。

**後:** タッチでも反応する。やったことは2階層:

- **第1段:** チャート枠に `cursor-pointer` と `touch-manipulation` を付与 → iOS の 300ms タップ遅延が消える
- **第2段:** Recharts の onClick がタッチで不安定なので、自前で `onTouchEnd` を仕込んで指の x 座標 → 分への手動換算を行うフォールバックを追加

これで PC・iPhone・iPad で同じ感覚でチャートタップによる投与追加ができるようになった。

---

## 2. 鎮静薬の mini-chart からも投与追加 (5-H-2)

メインチャート (オピオイド + Burden Index) の下に並んでいる鎮静薬カード — Propofol, Dex, Remimazolam, Ketamine の各小さい glass カード — も**そのカード上でタップして投与追加**できるようになった。

タップ位置に出る popover は `drug` が**そのカードの薬剤に固定**されてオープン。例えば Propofol カードをタップすれば、popover の薬剤チップが Propofol に選択された状態で出てくる。違う薬を選びたければチップで切り替えれば良い。

これによって「鎮静薬を打ちたい時はメインチャートに戻ってからタップする」という遠回りが無くなった。

---

## 3. 時刻モードで原点をずらしても投与時刻が変わらない (5-H-3)

**バグ:** 時刻モード (Clock mode) で原点 (start time) を画面で「見やすい時間」に手動変更すると、すでに入力した投与イベントの絶対時刻が**一緒にずれてしまう**問題があった。

**例:**
- 原点 10:42、Fent ボーラスを投与イベントとして 30 分後 (絶対 11:12) に追加
- 「グラフを見やすくしたいから原点を 11:00 に変えよう」とすると、Fent が原点からの相対 30 分のまま保たれて絶対 11:30 になってしまう

**修正後:** 原点をユーザーが手動変更すると、すべてのイベントの相対時刻 (`event.time`) が**逆方向に補正される**。

```
原点 10:42 → 11:00 (+18分)
Fent の event.time が 30 → 12 に補正
絶対時刻 = 11:00 + 12 = 11:12 ✓ (元の絶対時刻が維持される)
```

24時間境界 (例: 23:00 → 01:00) も小さい方向にラップ補正するロジック入り。

「原点は表示の都合で動かせる、薬剤の絶対時刻は不変」という時刻モードの直感的な期待に合うようになった。

---

## 4. マーカータップで編集・削除 (5-H-3)

**前:** チャート上のマーカー (▼ ボーラス、▶ infusion) をタップしても何も起きず、修正は画面下の「現在の投与スケジュール」リストの編集ボタンから行うしかなかった。

**後:** マーカーをタップすると popover が**編集モード**で開く。

- ヘッダーに「Editing」(編集中) ラベル
- ドーズ・時間・薬剤・タイプが既存値で **pre-fill**
- 下部に **Update** (更新) ボタンと **Delete** (削除) ボタン
- Update を押すと event が新しい値で置換 (id 維持)、Delete で削除

```
[ Editing                ×  ]
  Drug: [Fent] [Remi] [Mor] ...
  Type: [● Bolus] [○ Infusion]
  Dose: [- 25 +]  unit: mcg
  Time: [- 30 +] min
  
  [   Update   ]  [ Delete ]
```

メインチャートと鎮静薬 mini-chart 両方で動作。

---

## 5. マーカーをドラッグして時刻変更 (5-H-4)

これが今回の目玉。

**動作:**
- ▼ ボーラスマーカーや ▶ infusion 開始マーカーを**指でつかんで横にスライド**
- マーカーが指に追従、Cp/Ce 線が**リアルタイムで再計算・再描画**
- 指を離すと新しい時刻で確定

```
時刻 30 分の Fent を 50 分に動かしたい:
  指でつかむ → 右にスライド → 離す
  
  ▼Fent          →     ▼Fent
  |                          |
  +-------|--------|---------+--------|--→ time
  0      30      45         50       60
```

**タップとドラッグの区別:**
- 指の移動が **5 px 未満** → タップ扱い (既存通り、編集 popover が開く)
- **5 px 以上** → ドラッグ扱い (時刻変更、popover は出ない)

**iPhone/iPad もそのまま動く:**
- Pointer Events API でマウス・タッチ・ペンを統一処理
- ドラッグ中の横スワイプを `touch-action: pan-y` でブラウザに渡さないので、ページが横にスクロールしない
- 縦スクロールは許可されるので、ドラッグしないなら普通にページを上下に動かせる

**Infusion をドラッグした場合:**
- 開始マーカー (▶) や持続区間バーをつかんで動かすと、infusion 全体 (start・area・end) が同じだけシフト
- duration (継続時間) は変わらない (5-H-4 v1 の仕様)
- ※ 終了マーカー (◀) を動かして duration を変更する操作は次のフェーズ (5-H-7) で予定

## 6. メニュー項目の日本語化 (5-H-5)

`日本語` モード時の薬剤・モデル選択メニューが少し読みやすくなった。

**変更点:**
- 薬剤プルダウンのカテゴリ見出し:「Opioids / Sedatives」→「**オピオイド / 鎮静薬**」
- PK モデル名の population 部分:「Adult / Pediatric」→「**成人 / 小児**」
  - 例: `Bae (2020) Adult` → `Bae (2020) 成人`、`Ginsberg (Pediatric)` → `Ginsberg (小児)`

著者名 (Bae, Eleveld, Hannivoort 等) と発行年は**国際記号としてそのまま**残してある。"Neonate" "PICU" "Peds/Adult" "S-ketamine" 等の専門識別子も触らない方針 (麻酔科医にとっては英語のまま読みやすい)。

最小スコープでメニューの肌触りだけ整える、という判断。

## 既知の課題 (現行)

- **マーカーで duration を直接変更する操作**: 終了マーカー (◀) ドラッグで infusion の継続時間を伸縮させる機能は次フェーズ (5-H-7) 予定
- **ダークモード**: 夜勤・暗所での視認性向上 (Phase 5-I-1) で予定
- **Saved Scenarios の鎮静薬プリセット**: 実用度低の判断で保留
- **Bouillon Propofol×Remi 相互作用**: 麻酔深度予測の精度向上に有効だがスコープ大、次のフェーズ候補
- **App.jsx の分割**: 1700 行超、技術的負債だがユーザー体験には影響しない

---

## 設計思想

- **既存の opioid-only ワークフローを壊さない**: 鎮静薬を使わないセッションでは UI が変わらない
- **嘘をつかない**: 文献にある PD だけを描画 (Ketamine の Cp-only、Dex の advanced toggle 等)
- **段階的ロールアウト**: 1 commit = 1 sub-phase、問題があれば revert で完結
- **タッチ優先**: ベッドサイドで iPhone/iPad 片手操作を想定したインタラクション設計

ベッドサイドでの「ちょっと試してみる」を、視線をグラフから外さずにできるツールを目指している。
