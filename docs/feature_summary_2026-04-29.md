# Anesthesia PK/PD Simulator — 直近の機能追加サマリー (2026-04-29)

これは Phase 5-G-2 と Phase 5-H-1 で何が変わったかを、コードを見ない人向けに書いたメモです。

---

## 1. 鎮静薬カードを別グラフにした

**前:** Propofol を打つと、メインチャート（オピオイド + Burden Index 用）に Propofol の Cp/Ce 線が混ざって描かれていた。単位スケールが違うのを無理やり合わせていて、軸の意味も混濁していた。

**後:** メインチャートは **オピオイド専用**。鎮静薬を打つと、メインチャート直下に**薬剤ごとの小さな glass カード**（高さ 160px 程度）が縦に並んで出る。鎮静薬を1つも打っていない時はカード自体が表示されない（普段の opioid 運用では UI が変わらない）。

```
┌─────────────────────────────────────────────────┐
│ Concentration (Cp & Ce)                         │
│ … メインチャート (オピオイド + Opioid Burden) … │
└─────────────────────────────────────────────────┘
（鎮静薬 event がある時のみ↓）
┌─────────────────────────────────────────────────┐
│ Prop — Sedation monitor                         │
│ … Propofol mini chart …                         │
└─────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────┐
│ Dex — Sedation monitor                          │
│ … Dex mini chart …                              │
└─────────────────────────────────────────────────┘
```

---

## 2. 鎮静薬を 4 種に拡張

| 薬 | カラー | モデル | 表示の特徴 |
|---|---|---|---|
| **Propofol** | teal (青緑) | Eleveld 2018 完全 PD | BIS target 3-5 mcg/mL Ce 帯 (薄塗り) |
| **Remimazolam** | fuchsia (赤紫) | Eleveld 2025 完全 PD | GA 維持 Ce 0.4-0.8 mcg/mL 帯 |
| **Ketamine** | rose (深ピンク) | Noppers 2011 (S-form) | **Cp のみ表示**。375 ng/mL に熱痛 reference 線 |
| **Dexmedetomidine** | indigo (青紫) | Hannivoort 2015 (PK のみ) | **Cp デフォルト**。0.2-0.3 / >1.9 ng/mL の sedation バンド |

**何故薬ごとに違う表示なのか:**
- Propofol と Remimazolam は **Ce が論文で確実に決まっている** → Ce 線も描画、target 帯あり
- Ketamine は **PD endpoint が複数あって単一 ke0 で表せない**（鎮痛・鎮静・解離・EEG・循環がそれぞれ違う関係）→ Cp だけ。「Ce 利用不可」バッジ + 熱痛参考線のみ
- Dex は **論文で ke0 が報告されていない** → デフォルト Cp + 必要なら Advanced toggle で Colin 2017 の MOAA/S ke0 (0.0428/min) で Ce を計算可能

**それぞれ嘘をつかない設計** — 文献に書いてあることだけを描画する方針。

---

## 3. メインチャートのオピオイド線は変わらない

オピオイド (Fent / Remi / Mor / HM / Met / Suf) は今までどおりメインチャートに描かれて、Combined Opioid Burden Index も右軸で出る。鎮静薬を追加しても opioid 周りは何も変わっていない。

---

## 4. Y 軸を自由に調整できるように

各チャートのカードヘッダーに「Auto Y チェックボックス + スライダー + 数値表示」が追加された。メインチャートと SedationChart で**完全に同じパターン**。

- **Auto Y ✓**: データに合わせて自動スケール (デフォルト)
- **チェック外す or スライダー動かす**: 0 〜 任意の値で固定。スライダーは**平方根スケール**なので、左半分で細かい値（PD 観察用）、右半分でPK ピーク観察ができる
- 右に現在値の数値表示 (`Auto Y` or `1.50 ng/mL`)

これで Dex を打った瞬間の Cp スパイク (50 ng/mL) と sedation band (0.2-1.9 ng/mL) を**両方好きな解像度で見られる**。

---

## 5. メインチャートの Y 軸コントロールを上に移動

以前は下のコントロール帯（Time Axis と一緒）に Y 軸スライダーが入っていたが、SedationChart と統一するためにメインチャート**カード上部の見出し列**に移動。下の帯は Time Axis (clock mode / 6h-12h-24h プリセット / 時間スライダー) だけになって視認性が向上。

ついでに「`min`」ラベルが2回出ていた重複も削除（"Time Axis (min):" の見出しと、数値入力の右側の "min" の両方があった）。

---

## 6. グラフをクリックして投与イベントを追加

これが Phase 5-H-1 の目玉。

メインチャートのどこをクリックしても、**そのクリック位置にフローティングのカード**（glass エフェクト）が出てきて、

- ヘッダーに時刻 (clock mode は `12:30`、min mode は `30 min`)
- 薬剤チップ (Fent / Remi / Mor / HM / Met / Suf / Prop / Rmz / Ket / Dex の 10 種)
- Bolus / Infusion 切替
- ドーズ stepper (薬ごとの増分: Fent ±25 mcg, Prop ±10 mg など)
- 時間微調整 (±5m / ±1m / 直接編集)
- Add ボタン

を**1か所で全部完結**できる。Add を押すと event 追加 → カードが閉じる → Cp/Ce 線が即座に更新。

閉じる方法:
- 外側クリック
- Escape キー
- × ボタン

これによって「30分後にもう1発打ったらどうなるか見てみよう」という思考フローが、グラフから視線を外さずにできるようになった。

**注意:** 現状 PC マウスのみで動作。**iPhone/iPad のタッチでは反応しない**ので、別途対応が必要（次セクション参照）。

## 7. 鎮静薬の安全な扱い

**Dex** には常時注意書きが表示される:
> 「Dex の鎮静効果は文脈依存性が高く、覚醒・刺激・他剤併用・年齢・肝/心機能・ICU 病態により大きく変わる」

**Ketamine** にも常時注意書き:
> 「S-ケタミンの PK のみ (Noppers 2011)。ラセミ体ケタミンはモデル化されていないため、本濃度をラセミ体総濃度として解釈しないこと」

**Dex Advanced toggle** をオンにすると:
> 「Ce は Colin 2017 MOAA/S endpoint (ke0 = 0.0428/min) から導出。探索的 PKPD — 臨床投与判断には用いないこと」

つまり、シミュレータが「これは臨床判断ツールではなく教育/研究用」というスタンスを UI から明確に伝えるようになっている。
