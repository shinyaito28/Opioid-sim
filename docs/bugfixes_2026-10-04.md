# 基本不具合の修正（2026-10-04）

Fentanyl、Hydromorphone、Morphine、Propofolを主な検証対象としました。ローカル修正であり、commit・push・公開は行っていません。実患者情報や既存ブラウザの保存データは使わず、合成入力だけで検証しました。

## 修正した内容

- Fentanyl Bae2020は原著Table2（p.980）の容積指数1.23、Cl/Q指数0.313へ修正。70kgの基準係数とke0は維持。原著のQ1/Q2はコードのQ2/Q3に対応します。DOI:10.1016/j.bja.2020.06.066。
- Propofol／Remimazolamのtooltip・現在値・範囲外ピーク表示を表示単位へ換算。サマリーの閾値は内部ng/mLで一度だけ比較します。
- Ketamine／Dexのke0=0ではCeをnull（未計算）とし、Cpだけを描画。サマリーもピークCpを表示し、未計算のCeを0と判定しません。Ketamine参照線のオブジェクト渡しも修正。
- 体重・身長・年齢、投与量、期間、モデル、単位、ID、保存形式、濃度帯の順序を検査。不正な変更は反映せず、計算不能な状態は結果表示を止めます。非有限数を正常な0へ置換する処理を廃止。
- 10秒後の状態を開始時刻へ記録していた問題を修正。イベント時刻で区間を分けるRK4で計算し、同じ時刻に標本化します。1分標本と、端数の終了時刻を保持。小数投与時刻も10秒境界へ丸めません。
- autoFillStatsを保存し、既定をOFFへ変更。読込直後の自動補完で保存患者属性を置き換えません。シナリオには全選択モデル、濃度帯、Clock Mode、開始日・時刻を保存・復元します。
- localStorageの読込・保存失敗を通知。無効な保存はそのまま保持し、自動保存を停止。旧比較線は計算版を確認して表示し、旧版データは削除しません。
- Clock Modeの開始日を保持・表示。日跨ぎ入力は現在の経過時間に近い日として解釈し、開始時刻の移動でも投与の絶対時刻を保持します。日付がない旧保存は読込日の開始として扱うため、開始日の確認が必要です。
- 履歴の編集開始で元イベントを削除しません。確定時に同一IDだけを更新。保存速度は絶対量なので、体重が変わった時は/kg表示と編集初期値を現在体重で再換算します。
- 新規の速度変更は明示したseriesId内でのみ区間を整理します。系列のない既存投与に重なる追加は、対象が曖昧なため記録を変えず拒否し、履歴からの個別編集を案内します。未標識の並行投与はまとめません。手入力した有限停止と次の速度変更による終了をseriesLimitで区別し、変更の後ろ倒し・削除でも前の無期限投与を復元します。既に短縮済みで元の停止条件が保存されていない記録は推測して延長しません。並行投与を明示選択する画面は次のUI検討対象です。
- 総投与量を表示計算期間内へ制限し、進行中の持続投与がある場合の停止後時間は表示しません。手動濃度帯をサマリーにも反映。
- Y軸のピークは表示する薬剤のCpとCe、互換性のある比較線から計算。非表示の別薬剤クラスで縦軸を拡大しません。
- 時間超過の集計は標本数ではなく実時間と標本間の線形補間で算出。AUCも実際の時刻差で積分。
- 薬剤切替／プリセットの未定義setIsAutoY呼出を修正。単位変更時の2桁丸めを廃止し、12桁で表示入力へ戻します。
- 「覚醒予測」「BIS Onset」等を、計算しているCe参考帯への到達・下限までの時間として表示。合算指標・AUCの定義と未検証範囲を明記し、具体的臨床介入を指示する文言を参考結果へ変更。警告なしの場合にも説明を表示します。

## 検証

`npm test`は35件。主要4薬剤について18歳35kg女性、35歳70kg男性、80歳100kg女性の12合成ケースを、同じPKパラメータに対する独立したSciPyの行列指数関数解と比較します。基準は絶対誤差1e-5ng/mLまたは相対誤差2e-6の大きい方。小数時刻のbolusと重なる有限infusionを含みます。

別の1区画解析解、Bae原著指数、26単位の往復換算、並行投与の線形加算と独立停止、速度変更、入力拒否、期間集計、保存復元、日跨ぎ、体重変更後の表示も確認します。fixturesは合成データです。基準解の再生成は、式やモデルを変える場合にレビューして行ってください。

```sh
node tests/export-reference-input.mjs
python tests/generate_reference.py
npm test
```

基準解の再生成だけにPython＋NumPy／SciPyが必要です。通常のテストは保存済みfixtureを使い、追加依存は不要です。

ビルドと、外部ページ通信を遮断した隔離Chromiumの画面操作でも確認。ブラウザのテストは端末固有の検証用スクリプトで、通常のnpm testには含みません。

## 未解決の臨床的検証と次のUI

Hydromorphone／Morphine等のke0とPD閾値のendpoint整合性、簡略・出典不明モデル、成人由来濃度帯の小児適用、Propofol式の全共変量、腎肝機能・耐性・代謝物・鎮静薬相互作用は未検証です。これらの数値は推測で変更していません。数値解との一致は原著実装や患者への妥当性を保証しません。

次のUI案は、主要4薬剤の固定表示、Nowを基準とした時刻入力、持続投与カードに現在速度と「速度変更」「停止」をまとめる構成です。速度変更では前区間を自動終了し、別ポンプの並行投与は別操作と系列で明示。記録した実投与と将来の予定を区別し、変更後の時刻・絶対量・単位を一画面で確認できるようにします。今回はこの大きな画面変更は実装していません。

独立レビュー後の追加検証：未標識の同時／異時刻並行投与の保全、別ポンプの保全、速度変更の後ろ倒し・削除、手入力した有限停止を確認。Clock Modeの履歴編集中は自動時刻追従を停止。改行警告はpackage.jsonの変更2行のみLFへ修正。
率のみの編集・変更なしの保存では元の停止条件を維持し、薬剤・投与種別を変えた場合は旧系列も再計算します。
